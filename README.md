# Blog Posts Service API

Blog Posts Service API is a Spring Boot REST API service managing Post records.

## Features
- Create/update blog layouts
- Dynamic comment mappings
- Category lists index

## Running Locally
Run `mvn spring-boot:run` in the project directory. The service runs on port `8080`.
